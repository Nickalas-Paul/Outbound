# Outbound documentation

## Folders

- **`docs/roadmap/`** — Project specification and phase plan versions.  
  **`docs/roadmap/outbound-project-spec-v3.md.docx` is the authoritative roadmap.**  
  v1 (`outbound-project-spec-v1.md`) and v2 (`outbound-project-spec-v2.md.docx`) are superseded and kept for history only.

- **`docs/handoffs/`** — Sealed phase handoff documents (Phases 0–3). Each phase seal adds a handoff here before merging to `main` and `develop`.
