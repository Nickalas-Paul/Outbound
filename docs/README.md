# Outbound documentation

## Folders

- **`docs/roadmap/`** — Project specification and phase plan versions.  
  **`docs/roadmap/outbound-project-spec-v4.md` is the authoritative roadmap.**  
  Earlier versions (v1–v3 / v3.1) are superseded and kept for history only.

- **`docs/handoffs/`** — Sealed phase handoff documents (Phases 0–3). Each phase seal adds a handoff here before merging to `main` and `develop`.

- **`docs/parity-checklist.md`** — Web / Android verification checklist for Phase 4 Step 1 (filled after the Android dev build is available).
